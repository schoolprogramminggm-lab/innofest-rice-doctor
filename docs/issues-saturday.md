## C. Функция `format_answer` — текст ответа бота

**Метки:** `бот` · **Этап:** 2. Прототипы · **Время:** ~20 мин

### Цель
Написать функцию, которая из диагноза и уверенности собирает готовый текст ответа бота.

### Что сделать
- [ ] В файле `bot/texts.py` написать функцию:
  ```python
  def format_answer(label, confidence, lang):
      # label - класс, например "blast"
      # confidence - уверенность от 0 до 1, например 0.91
      # lang - язык: "ru" или "kk"
      ...
  ```
- [ ] Если `confidence >= 0.6`, функция возвращает (`return`) текст:
  ```
  🩺 Диагноз: Пирикуляриоз
  📊 Уверенность: 91%
  ```
- [ ] Если `confidence < 0.6` — текст «🤔 Не уверен. Сфотографируйте лист ближе, при дневном свете, на однотонном фоне.»
- [ ] Названия болезней хранить в словаре, например `NAMES = {"ru": {"blast": "Пирикуляриоз", ...}, "kk": {...}}`
- [ ] Внизу файла проверить на 3 примерах:
  ```python
  print(format_answer("blast", 0.91, "ru"))
  print(format_answer("healthy", 0.75, "kk"))
  print(format_answer("brown_spot", 0.40, "ru"))
  ```
- [ ] Коммит и push

### Готово, когда
- `python bot/texts.py` печатает 3 правильных ответа (третий — «не уверен»)

### Подсказки
- Проценты: `f"{confidence:.0%}"` превращает `0.91` в `91%`.
- Перенос строки внутри текста — `\n`.
- Названия классов на казахском — в README, раздел 3.
